# אפליקציית לימוד אותיות עבריות

אפליקציה אינטראקטיבית ללימוד אותיות האלפבית העברי (דפוס + כתב) עם משחקי זיכרון ושמיעה.

## איך להשתמש
1. פתח את `index.html` בדפדפן.
2. ודא שתיקיית `audio/letters/` נמצאת עם קבצי ה-MP3 של כל אות.

## העלאת קבצי אודיו
העלה את תיקיית `audio` (עם תת-תיקייה `letters`) למאגר דרך ממשק GitHub או דרך האתר.

## GitHub Pages
לאחר העלאה, הפעל Pages מהענף Settings > Pages.
